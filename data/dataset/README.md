# Dataset

**Multilingual Customer Support Tickets** (Kaggle). Se versiona en el repo
(privado, solo el grupo tiene acceso) para que cloná y funciona sin pasos
manuales adicionales:

- `aa_dataset-tickets-multi-lang-5-2-50-version.csv`
- `dataset-tickets-german_normalized.csv`
- `dataset-tickets-german_normalized_50_5_2.csv`
- `dataset-tickets-multi-lang-4-20k.csv`
- `dataset-tickets-multi-lang3-4k.csv`

Columnas: `subject`, `body`, `answer`, `type`, `queue`, `priority`, `language`,
`business_type`, `tag_1`..`tag_9`.

Para el notebook se usa principalmente `dataset-tickets-multi-lang-4-20k.csv`
(mayor volumen) salvo que se indique otra cosa en el notebook.
